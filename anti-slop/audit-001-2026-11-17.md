# Anti-Slop UI Audit 001 (2026-11-17)

Mode: `after` (audit only — no UI files modified yet).

1. **[HIGH | A11y / Focus]** `frontend/src/views/WorkspaceView.vue` (L2290, L2405) & `frontend/src/App.vue` (nav/header controls): Several checkboxes and custom buttons use `focus:outline-none` or omit `focus-visible:ring-2`, making keyboard navigation invisible.
2. **[HIGH | Mobile Layout & Overflow]** `frontend/src/App.vue` (L46) & `frontend/src/views/WorkspaceView.vue` (L1766): The top header bar lacks `flex-wrap` on narrow screens (`375px`), and the chapter table wrapper uses `overflow-hidden` without `overflow-x-auto`, clipping action buttons on small viewports.
3. **[MEDIUM | R-12 Elevation Discipline]** `frontend/src/style.css` (L60): Every `.card` carries `shadow-lg shadow-black/20`, so base panels share elevation with floating modals; base cards should sit flat (`border-ink-700` only) and reserve shadows for modals/popovers.
4. **[MEDIUM | Contrast / WCAG AA]** `frontend/src/App.vue` (L143) & `frontend/src/views/WorkspaceView.vue`: `text-slate-500` (`#64748b`) on dark `--ink-900`/`--ink-950` (`#11141b`/`#0b0d12`) falls slightly below 4.5:1 contrast for readable status/metadata labels; promoting readable muted text to `text-slate-400` fixes contrast while keeping hierarchy.
5. **[MEDIUM | R-10 Glassmorphism Restraint]** `frontend/src/App.vue` (L45) & `frontend/src/views/WorkspaceView.vue` (L2917): `backdrop-blur` on the top header and modal scrim adds unnecessary blur layering; a solid `bg-ink-900` header improves legibility in both Light and Dark themes.
6. **[LOW | Tap Targets]** `frontend/src/App.vue` (L83, L99) & `frontend/src/views/WorkspaceView.vue` (L1711): Header toggles (`px-2 py-1`) and compact table action controls are tight on touch screens; adding responsive padding (`min-h-[36px]` on mobile) improves tap ergonomics without bloating desktop tables.
